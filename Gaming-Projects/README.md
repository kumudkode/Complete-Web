# Gaming Projects Collection 🎮

Welcome to the Gaming Projects section! This collection contains web-based games that demonstrate various web development concepts covered in the Complete Web Development course.

## Directory Structure

### 📁 Basic-HTML-CSS
Games that use only HTML and CSS - perfect for Phase 0 and Phase 1 learners:
- **CSS-Only Hover Game**: Interactive hover-based game using CSS animations
- **Animated Racing Game**: Pure CSS animation showcase
- **Memory Card Flip**: CSS transition and transform practice

### 📁 JavaScript-Interactive
Interactive games using JavaScript - great for Phase 2 learners:
- **Tic Tac Toe**: Classic game with DOM manipulation
- **Rock Paper Scissors**: Event handling and game logic
- **Number Guessing Game**: Input validation and feedback
- **Simple Calculator Game**: Math operations with fun twist

### 📁 Advanced-Games
Complex games for advanced learners:
- **Snake Game**: Canvas manipulation and game loops
- **Memory Matrix**: Advanced DOM manipulation
- **Typing Speed Test**: String manipulation and timing
- **2048 Game Clone**: Complex game logic and animations

## Learning Objectives

Each game is designed to teach specific web development concepts:

- **HTML Structure**: Semantic markup and accessibility
- **CSS Styling**: Layouts, animations, and responsive design  
- **JavaScript Logic**: DOM manipulation, event handling, and algorithms
- **User Experience**: Interactive design and feedback
- **Code Organization**: Clean, maintainable code structure

## How to Use

1. Navigate to any game directory
2. Open the `index.html` file in a web browser
3. Study the code to understand the implementation
4. Try modifying the games to add new features!

## Prerequisites

- Basic understanding of HTML, CSS, and JavaScript
- A modern web browser
- Text editor for code exploration

Happy Gaming and Learning! 🚀
